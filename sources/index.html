Stockholms stadsbibliotek

Officiell
Bibliotek & öppen verksamhet
Webb Kalender

Stockholm · Import: manual · 4 aktiviteter · Kontrollerad 25 november

Ingen RSS/iCal hittad. Evenemangslistan renderas med JavaScript (Next.js). Filtrering fungerar via URL-parametrar, t.ex. /evenemang?categories=Rim+och+ramsor&categories=S%C3%A5ngstund&startDate=2026-11-25&stopDate=2026-12-12. Kategorier: Sagostund, Rim och ramsor, Sångstund m.fl. Frontendens JS anropar ett odokumenterat GraphQL-API på https://biblioteket.stockholm.se/graphql (queries eventSearch, getEventBySlug, getEventSearchFilters) – INTE testat/verifierat av oss; använd endast med tillstånd. Enskilda evenemangssidor (/evenemang/<slug>) är serverrenderade och kan läsas utan JS. Stadsbiblioteket Odengatan 53 är stängt för renovering till början av 2028; ersättning Spelbomskan (Odengatan 59).

Webb Kalender Instagram @haningekommunFacebook @haningekommun Flöde

Haninge · Import: rss · 22 aktiviteter · Kontrollerad 25 november

RSS 2.0 verified (application/rss+xml). Returns only ~10 nearest upcoming items (title, link, description with 'Tid: YYYY-MM-DD HH:MM' and 'Plats:'); paging/count params ignored. Event detail pages list all occurrence dates under 'Evenemanget äger även rum'. HTML list paginates via ?&page=N and links occurrences with ?d=YYYY-MM-DD. No iCal found. Covers library, culture, sport and association events (incl. FutureTeens, Vendelsö ridskola). Server-renderad lista, pagineras med ?&page=N (sid 1–3 täckte 25 nov 2026–7 mars 2027). Varje evenemang har egen sida /evenemang-och-aktiviteter/<slug>/ (?d=YYYY-MM-DD för förekomst). Inget RSS/iCal och ingen schema.org Event JSON-LD hittades – skrapning av HTML krävs. Kulturkalender: https://haninge.se/uppleva-och-gora/kultur-konst-och-bibliotek/kulturevenemang/kalender-kultur-i-haninge/
